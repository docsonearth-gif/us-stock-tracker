# 美股 RS 排名與大盤廣度（每日自動）

羅傑交易系統的美股版，台股 `tw-stock-tracker` 的移植。每個交易日收盤後自動下載美國主要交易所（NYSE、Nasdaq、AMEX）全部普通股，計算：

- 個股 **RS 評分**（1–99）、短期 RS、Minervini **第②階段**、每日選股清單
- **大盤廣度**（52 週新高／新低、出貨日、市場狀態）與**市場寬度**（站上 20／50／200 日線比例，全部／NYSE／Nasdaq）
- 大盤修正時的 **Utility Screen**（基準 S&P 500）
- **VCP 先決條件**、**52 週新高**名單
- **Market Monitor**（仿 Stockbee：4% 突破家數、5／10 日比、T2108、季漲跌 25%）
- **產業強度**（Nasdaq 產業別）與**自訂主題板塊**（主題 ETF 成分股＋手動補充）的強度排名與板塊 RSI 熱圖
- **ETF 強度與 RSI 熱圖**：大盤、11 個類股、產業、主題 ETF（台股官方類股 RSI 的美股版）

已排除：ETF、權證、權利、單位、特別股、SPAC、OTC、發行前交易。

## 每日報告（PDF）

`report/美股每日報告.pdf`（最新）、`report/archive/YYYY-MM-DD.pdf`（每天一份）；同步到 Google Drive「美股每日資料」。

順序同台股：**大盤 → 板塊 → 個股**。規則依美股回測（`data/backtest_report_us.md`）定案：

| 項目 | 規則 |
|---|---|
| 主流 | 創 52 週新高 ≥ 3 檔且創高股平均收紅＋板塊成交額比（5 日均 ÷ 50 日均）≥ 1.3（產業、主題都看） |
| 醞釀 | 成交額比 ≥ 1.3、創高 < 2（只列主題；產業回測沒有優勢） |
| 啟動 | 創高 ≥ 3 且收紅、成交額還沒放大 |
| 尾聲／退潮 | 前 4 個交易日曾是主流，今天只剩一項／兩項都沒有 |
| 產業排名 | RS 中位數排名，和 1 週、3 個月、6 個月前比（J Law） |
| 候選股 | 第②階段＋RS ≥ 85＋股價 ≥ 12＋50 日均成交額 ≥ 2,000 萬美元，且在主流板塊或 RS 前 20% 產業；主流優先，再依加分項數、RS 排序，列前 15 |
| 加分項 | EPS≥20%、EPS 加速、轉盈、營收≥20% 且加速（SEC 財報）、強勢 IPO（近 3 年上市） |
| 財報日 | Nasdaq 財報日曆；7 天內標 ⚠ |

不放 VCP、RS 線、新晉 RS90 等個股訊號（同台股，這些在 Excel 裡）。門檻可用 `SIG_NEW_HIGHS`、`SIG_DOLLAR_VOL_RATIO`、`MIN_RS`、`MIN_PRICE` 調整。

SEC 要求連線帶聯絡方式；若基本面一直空白，在 repo Secrets 加 `SEC_USER_AGENT`（例如「Your Name your@email.com」）。

## 什麼時候更新

| 台北時間 | 內容 |
|---|---|
| **週二～週六 06:30** | 前一個美股交易日的行情、RS、大盤廣度、Market Monitor、ETF、板塊（分類每週更新一次） |

GitHub 排程常延遲。想馬上跑：**Actions → 美股 RS 每日計算 → Run workflow**（或改 `run.txt` 推上來）。

漏跑幾天沒關係，下一次會自動補齊（最多往回 10 天）。

## 資料來源

| 用途 | 來源 | 說明 |
|---|---|---|
| 每日行情 | EODHD Bulk API | 一次呼叫抓整個美國市場某一天（約 100 次額度）；漏跑的日子下次自動補 |
| 第一次回補 | EODHD 單檔日線 | 約兩年（成交量曾因存檔格式錯誤被截掉尾端的 0，已用 Bulk API 重抓修正） |
| 回測 | EODHD 長歷史 | 2014 年起＋8,180 檔已下市股票，存在 **Releases** 附件（`us_history_long.tar`），價格與成交量都正確 |
| 產業別 | Nasdaq 股票篩選器 | 每週更新 |
| 主題板塊 | 主題 ETF 發行商的持股檔（SPDR、Global X、ARK、iShares、First Trust） | 每週更新；抓不到的主題沿用上一版 |
| ETF | EODHD 單檔日線 | 每天重抓約兩年 |

**還原股價**：每日檔存當天「含分割、含配息」的報酬率（`ret`），計算時連乘回去。之後再分割或配息，舊資料都不用改。
Bulk API 的報酬率＝(收盤＋除息股利) ÷ (前一日收盤 ÷ 分割比例) − 1；有分割或漲跌超過 ±35% 的股票（反分割常不在分割清單裡），改用該檔的還原價重算。
已驗證：2026-11-10 用 Bulk 重算 5,606 檔，收盤 0 檔不一致、報酬率差超過 0.5 個百分點只有 1 檔。

備用：`SOURCE=yahoo` 可改用 yfinance（不用 EODHD 時）。

## 檔案

### `RS_美股.xlsx`（每個工作表 A1 是資料日期）

| 工作表 | 內容 |
|---|---|
| 大盤廣度 | 近 60 天：新高／新低、新高股收紅收黑與「新高大跌≥5%」、第②階段比例、站上 20／50／200MA 比例（全部／NYSE／Nasdaq）、S&P 與 Nasdaq 出貨日、指數廣度背離、市場狀態 |
| 52週新高 | 當天創 52 週新高的股票，依成交額排序 |
| Utility Screen | S&P 500 距高點 21–200 個交易日才有名單 |
| 必要條件候選 | 第②階段＋RS ≥ 85＋股價 ≥ 12 美元＋50 日均成交額 ≥ 2,000 萬美元（J Law 美股條件） |
| VCP先決條件 | 同 TradingView `trend_template.pine`（不看 150MA） |
| 做空觀察 | 依 Notion「沽空」筆記選股：50 日均成交額前 1,500（排除小型股）、股價 ≥ 12 美元、過去一年 RS 曾 ≥ 80、52 週高點在 21 天以前（做頭 ≥ 一個月）、RS 線持續往下（在自己的 21 日均線之下且均線下彎，不設分數門檻）、50MA 向下；股價在 200MA 之下，或還在 200MA 之上但已跌破下彎的 50MA（早期）。狀態：反彈到200MA附近／反彈到50MA附近／在200MA之下／剛跌破200MA／早期（未跌破200MA）；參考止損：200MA 類看 200MA × 1.045，50MA 類與早期看 50MA × 1.045；美股另列下次財報（10 天內 ⚠）。標題寫指數相對 200MA 與「指數反彈失敗」提醒 |
| 全部股票 | 每檔普通股的 RS、短期 RS、第②階段、距高點、距 50 日線、RSI14、成交額 |

| 自訂板塊強度 | 主題板塊依 RS 中位數排名：RS 1 月中位數、排名 5／20 日進步、板塊 RSI、第②階段比例、近 10 日創高比例、龍頭候選 |
| 產業強度 | Nasdaq 產業別，算法同上 |

## 和台股版的差異

| 項目 | 台股 | 美股 |
|---|---|---|
| 市場寬度均線 | 20／60／240 | 20／50／200 |
| 出貨日成交量 | 全市場成交金額 | S&P 用 NYSE 股票成交量；Nasdaq 用 Nasdaq 股票成交量 |
| 出貨警訊 | 新高股收黑 ≥ 40% 或新高跌停 ≥ 2 | 新高股收黑 ≥ 40% 或新高股收跌 ≥ 5% 有 5 檔以上 |
| RS 排名範圍 | 全部普通股 | 股價 ≥ 1 美元的普通股 |
| Utility 自低點 RS | 低點後 5 天 | 低點後 3 天（沒有漲停擠在一起的問題） |

`MIN_RS`、`MIN_PRICE`（美元）、`MIN_DOLLAR_VOL_M`（百萬美元）、`RS_MIN_PRICE`、`NH_DROP`、`NH_DROP_N`、`UTILITY_*`（同台股版，成交額門檻改 `UTILITY_MIN_DOLLAR_VOL_M`）

## EODHD 額度

每天 100,000 次（UTC 00:00 歸零＝台北 08:00）。Bulk API 一次算 100 次。每日流程約用 400 次（行情、分割、股利三個 Bulk＋61 檔 ETF＋少數重算），很充裕；大量回補、修正才要注意。
